# 2026.1106.2

This fork release builds on upstream 2026.1106.0 and retains the HTTP onboarding
fix from 2026.1106.1.

- Explain unavailable Assistant Connection (MCP) routes in the catalog, setup,
  and account-wide connection management instead of offering a permanent retry.
- Stop connection polling after a missing static endpoint; preserve normal
  handling of authentication, temporary failures, and missing grants.
- Document the HTTPS deployment requirement and HTTP loopback exception.

Fixes the UI failure described in paperclipai/paperclip#19924. This does not
enable OAuth/MCP over non-loopback HTTP.
